# Overview

As a software engineer, I want to build a solid foundation in each new language and tool I learn, starting with a working development environment and a complete workflow from code to a published repository. This project is my first step with Java.

This is a small console program written in Java. It prints "Hello World", greets the user by name using a method, and counts down with a loop before displaying a final message.

I created it to confirm that my Java setup works (JDK, VS Code, and Git) and to practice the basics I will use in larger Java programs: classes, the `main` method, variables, loops, and methods.

https://youtu.be/spirPjYMs4E?si=FFdI2x4-2gjebCa1

# Development Environment

I wrote the program in Visual Studio Code with the Extension Pack for Java, compiled it with the Eclipse Temurin JDK 21, and used Git and GitHub for version control and publishing.

The program is written in Java 21.

To compile and run it from the project folder:

```
javac -d out src/HelloWorld.java
java -cp out HelloWorld
```
